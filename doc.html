DayZero Technical Guide

A step-by-step walkthrough explaining every file, mathematical formula, Web API, and architectural design decision in DayZero. Crafted specifically for developers and beginners to learn modern web engineering.

1. Project Overview & Philosophy

DayZero is an immersive countdown telemetry instrument designed for software developers. Instead of generic to-do lists or distracting gamified clocks, it visualizes the passage of time across 4 calendar horizons: Today, This Week, This Month, and This Year.

💡
The "Zero-Bloat" Architecture Decision

Many modern web applications require gigantic toolchains (Webpack, Vite, Tailwind CLI, hundreds of MBs in node_modules). DayZero was purposefully built using Vanilla HTML5, CSS3, and JavaScript with zero external npm runtime dependencies. It loads in under 30 milliseconds, has zero build delay, and runs identically on any browser, laptop, phone, or tablet.

3. Deep Dive: server.js (The Backend)

Let's look at how server.js works. A beginner might ask: "Why didn't we use Express.js?"

Node.js already has everything needed to build a blazing-fast, secure static web server built right into its core standard library: http, fs, and path.

Core Highlights in server.js:

1. Directory Traversal Security Protection:

const filePath = path.join(PUBLIC_DIR, reqPath);

// Security Check: Prevent attackers from accessing files outside the folder (e.g., ../../windows)
if (!filePath.startsWith(PUBLIC_DIR)) {
  res.writeHead(403, { 'Content-Type': 'text/plain' });
  res.end('403 Forbidden');
  return;
}

2. Permissions-Policy Headers for Modern Web APIs:

Modern browsers restrict features like keeping the screen awake (screen-wake-lock) or going full screen unless allowed. We configure these headers explicitly: 

res.writeHead(200, {
  'Content-Type': contentType,
  'Cache-Control': 'no-cache, no-store, must-revalidate',
  'Permissions-Policy': 'screen-wake-lock=(self), fullscreen=(self)'
});

3. Efficient Streaming:

Instead of reading the entire file into memory using fs.readFileSync (which is slow for large files), we use fs.createReadStream(filePath).pipe(res) to stream data directly to the client as chunks.

6. Countdown Mathematics (Zero Timer Drift)

A common mistake beginner developers make when building timers is doing: 

// ❌ THE WRONG WAY: Accumulates timer drift!
let secondsLeft = 3600;
setInterval(() => {
  secondsLeft--; // Browsers throttle intervals when tabs sleep or lag!
}, 1000);
⚠️
Why setInterval Drifts

JavaScript's setInterval does NOT guarantee execution at exact 1000ms intervals. If your computer sleeps, the browser tab goes into background suspension, or the CPU spikes, missed ticks cause the timer to fall behind real time by minutes or hours!

✅ The Correct Solution in DayZero: We never decrement a counter. Instead, we always measure the delta against real-world calendar timestamps using new Date(): 

const now = new Date();

// 1. Compute today's exact midnight boundary
const startOfDay = new Date(now.getFullYear(), now.getMonth(), now.getDate(), 0, 0, 0, 0);
const endOfDay   = new Date(now.getFullYear(), now.getMonth(), now.getDate() + 1, 0, 0, 0, 0);

const totalDayMs = endOfDay.getTime() - startOfDay.getTime();
const remainingDayMs = Math.max(0, endOfDay.getTime() - now.getTime());

// 2. Compute exact percentage
const remainingPct = (remainingDayMs / totalDayMs) * 100;

This ensures 100% accuracy across midnight rollovers, Mondays, month lengths (28, 29, 30, 31 days), and leap years. Even if the laptop closes for 6 hours, the moment it opens, the clock is instantly correct.

The SVG Circle Stroke Formula (Geometry in Code)

How does the circular progress ring fill up based on a percentage?

Remember geometry: Circumference \(C = 2 \times \pi \times r\).

  • Our circle radius \(r = 92\).
  • Circumference \(C = 2 \times 3.14159 \times 92 \approx 578.05\).

In SVG, stroke-dasharray sets the dash pattern length. Setting it to 578.05 means one dash wraps the whole circle. We can then hide a portion of the stroke using stroke-dashoffset: 

const CIRCUMFERENCE = 2 * Math.PI * 92; // 578.05

// Offset formula: When 100% remaining, offset is 0. When 0% remaining, offset is 578.05
const offset = CIRCUMFERENCE - (percent / 100) * CIRCUMFERENCE;
ringProgressElement.style.strokeDashoffset = offset;

7. Browser Web APIs Explained

1. Screen Wake Lock API

Have you ever propped your phone on your desk to watch a timer, only for the screen to turn black after 30 seconds? The Screen Wake Lock API solves this: 

let wakeLockSentinel = await navigator.wakeLock.request('screen');
💡
The Hidden Catch with Wake Lock

Whenever the user minimizes the browser or switches to another tab, the browser automatically releases the wake lock for battery saving. DayZero listens to document.addEventListener('visibilitychange') and automatically re-acquires the wake lock the instant you switch back!

2. Fullscreen API (User Gesture Requirement)

Browsers forbid web pages from forcing full screen automatically upon page load (to protect users from deceptive popups). Full screen must be triggered directly inside a user click handler: 

activateBtn.addEventListener('click', async () => {
  // Directly inside click callback satisfies the user-gesture security rule
  if (document.documentElement.requestFullscreen) {
    await document.documentElement.requestFullscreen();
  }
});

3. Touch Protection (Press-and-Hold Logic)

When you prop a phone or tablet next to your keyboard, accidental thumb grazes can misclick buttons. Touch Protection overlays a shield. To unlock, you must press and hold for 1.5 seconds.

We implement this using requestAnimationFrame and timestamps:

  • On mousedown / touchstart, record touchHoldStartTime = performance.now().
  • Each animation frame calculates progress: (currentTime - startTime) / 1500.
  • If the user releases early (mouseup / touchend), we cancel the frame and animate the progress circle back to 0.
  • If progress reaches 100%, trigger unlockTouch() and optional haptic feedback with navigator.vibrate().

4. Web Audio API (Synthesizing Sound Without Audio Files)

DayZero has an optional hourly chime. Instead of downloading an .mp3 file over the internet, we generate sound directly from pure math using the browser's AudioContext: 

const audioCtx = new AudioContext();
const osc = audioCtx.createOscillator();
const gain = audioCtx.createGain();

osc.type = 'sine';
osc.frequency.setValueAtTime(880, audioCtx.currentTime); // 880 Hz note (A5)

// Soft volume ramp down (exponential decay like a bell)
gain.gain.exponentialRampToValueAtTime(0.0001, audioCtx.currentTime + 1.2);

osc.connect(gain);
gain.connect(audioCtx.destination);
osc.start();
osc.stop(audioCtx.currentTime + 1.2);

8. package.json

Here is our package.json file: 

{
  "name": "dayzero",
  "version": "1.0.0",
  "description": "DayZero - Minimal, immersive countdown dashboard",
  "main": "server.js",
  "scripts": {
    "start": "node server.js",
    "dev": "node server.js"
  }
}

Notice there are zero dependencies in dependencies or devDependencies. This means:

  • You never need to wait for npm install.
  • No security vulnerabilities from third-party packages.
  • It runs instantly on any machine with Node installed.
